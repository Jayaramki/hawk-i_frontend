File Format Requirements

Required Columns:

  • Attendance Date - YYYY-MM-DD format
  • Employee Code - INA employee ID
  • Employee Name - Full name
  • In Time - HH:MM:SS format
  • Out Time - HH:MM:SS format

Sample Data:

Date Code Name In Out
2024-01-15 EMP001 John Doe 09:00:00 17:30:00
2024-01-15 EMP002 Jane Smith 08:30:00 18:00:00

Important Notes:

  • • File size must be less than 10MB
  • • Employee codes must match existing Inatech employee IDs
  • • Date format must be YYYY-MM-DD
  • • Time format must be HH:MM:SS (24-hour format)
